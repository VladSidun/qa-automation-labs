## Контракт варіанта

Непорожні PDF, PNG, JPEG до 5 MiB включно. Перевіряється заявлений MIME-тип і реальний byteLength даних, без аналізу сигнатури файлу. HTTP POST /files передає multipart file. Відповідь — JSON з непорожніми рядками id і url. Помилки: INVALID_FILE_SIZE, INVALID_FILE_TYPE, UPLOAD_UNAVAILABLE, INVALID_UPLOAD_FORMAT. Розмір і типи — навчальні уточнення до короткої умови.

Після успіху сховища журнал отримує назву, розмір, id, URL і фіксований через Clock момент. Журнал успіхів не поповнюється за відхилення файлу чи збою сховища. За відмови журналу помилка передається назовні; автоматичного видалення вже завантаженого файлу немає.

Показовий OrderService збережено за методичкою. Він не гарантує транзакцію між базою і листом: після помилки листа запис залишається. HttpRateProvider перевіряє тип поля rate, а не повну фінансову коректність курсу.

## Ізоляція

MSW працює з onUnhandledRequest: error. Після кожного тесту скидаються обробники, реальні таймери та шпигуни. Показовий час фіксується fake timers, у варіанті передається Clock. Запитів до реальної мережі немає.
