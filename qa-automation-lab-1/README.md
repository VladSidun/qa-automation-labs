# Лабораторна робота 1

Розгортання середовища автоматизації тестування. Варіант 12.

Виконавець: впишіть власне прізвище та ім’я. Група: впишіть свою групу.

## Суть роботи

Налаштувати TypeScript, Vitest, ESLint і Prettier. Виконати показовий приклад
із температурою та індивідуальне завдання: середнє арифметичне масиву чисел
із відхиленням порожнього масиву.

## Запуск у PowerShell

```powershell
node -v
npm -v
git --version
npm ci
npm test
npm run coverage
npm run lint
npm run typecheck
npm run format:check
```

Версії зі свого комп’ютера потрібно записати у звіт. Звіт покриття:
`coverage/index.html`.

`npm run test:watch` запускає спостереження за змінами. Для експерименту
змініть очікуване значення одного тесту, збережіть файл, перевірте помилку,
потім поверніть правильне значення. Вихід: `q` або `Ctrl+C`.

## Файли

- `src/temperature.ts` і `tests/temperature.test.ts` — показовий приклад.
- `src/average.ts` і `tests/average.test.ts` — варіант 12.
- `vitest.config.ts` — пошук тестів, середовище Node.js і пороги покриття.
- `tsconfig.json` — налаштування TypeScript зі строгими перевірками.
- `eslint.config.mjs` — правила статичного аналізу.
- `.prettierrc` і `.prettierignore` — форматування та виключення.
- `.gitignore` — файли, які не слід додавати до Git.
- `package.json` — команди й залежності; `package-lock.json` — їх точні версії.

## Специфікація варіанта

`calcAverage(numbers)` повертає суму елементів, поділену на їх кількість.
Округлення не виконується. Для порожнього масиву виникає `EMPTY_ARRAY`.
Додаткова перевірка відхиляє `NaN` і нескінченності з кодом `INVALID_NUMBER`.

Тести охоплюють додатні, від’ємні, дробові й нульові числа, масив з одним
елементом, порожній масив та нечислові значення. У першому тесті видно
схему Arrange — Act — Assert: підготовка, виклик, перевірка.

## Перевірене середовище

Windows, Node.js 24.14.0, npm 11.9.0, Git 2.47.1.windows.2.
Використовуйте Node.js 24 для цих зафіксованих залежностей.
Команда npm ci відтворює версії з package-lock.json.

Перевірено 15 тестів; рядки, гілки, функції та інструкції — 100 %.
У режимі спостереження підміна очікуваного 8 на 9 спричинила падіння тесту;
після повернення 8 усі дев’ять тестів calcAverage знову пройшли.
