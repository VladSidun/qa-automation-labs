## Специфікація страховки

Функція `calcInsurancePremium(carAge, drivingExperience, accidentFreeYears = 0)`
приймає кількість повних років і повертає вартість у гривнях.

| Вік авто           | Базовий тариф |
| ------------------ | ------------- |
| 0–5 років включно  | 1000 грн      |
| 6–10 років включно | 1500 грн      |
| Від 11 років       | 2000 грн      |

За стаж водіння менше 3 років додається 25 % базового тарифу.
За кожен безаварійний рік застосовується знижка 5 %, але не більше 30 %.
Знижка застосовується до суми після надбавки. Результат округлюється до копійок.
Числові тарифи є навчальними уточненнями до варіанта: методичка їх не задає.

Усі роки мають бути невід’ємними цілими числами. Безаварійний стаж
не може перевищувати загальний стаж водіння. Помилки:

- `INVALID_CAR_AGE` — некоректний вік авто.
- `INVALID_EXPERIENCE` — некоректний стаж водіння.
- `INVALID_ACCIDENT_FREE_YEARS` — некоректний або суперечливий безаварійний стаж.

Приклади: `(1, 3, 0)` → 1000; `(6, 2, 0)` → 1875;
`(1, 2, 1)` → 1187.50; `(11, 10, 6)` → 1400.

## Показовий тариф паркування

`calcParkingFee(minutes, options = {})` приймає цілу невід’ємну тривалість.
Перші 15 хвилин безкоштовні, 16–60 хвилин коштують 30 грн.
Кожна розпочата наступна година додає 20 грн, максимум — 200 грн.
Потім застосовується нічний коефіцієнт 0.5 і коефіцієнт вихідного дня 0.8.
Некоректна тривалість відхиляється з `INVALID_DURATION`.

Приклад: 600 хвилин → 200 грн; уночі → 100 грн;
уночі у вихідний → 80 грн.

## Історія TDD

Для страховки виконано шість повних циклів. Кожний новий набір тестів
спочатку запущено з помилкою, потім додано мінімальну реалізацію,
а рефакторинг перевірено на повністю зеленому наборі.

| Цикл | Вимога                                        | Red     | Green   | Refactor |
| ---- | --------------------------------------------- | ------- | ------- | -------- |
| 1    | перевірка років і узгодженості стажу          | 1223967 | 7a2fc2d | 6dc7ce7  |
| 2    | базовий тариф для авто до п’яти років         | 0783585 | 35578b9 | ceb5dd4  |
| 3    | тариф для авто від шести до десяти років      | f5a5d11 | ccee44a | 787b032  |
| 4    | тариф для авто від одинадцяти років           | 9aa89f0 | e036732 | bb1e8b3  |
| 5    | надбавка за стаж менше трьох років            | ff5974c | e4f3c6d | 8758993  |
| 6    | безаварійна знижка з межею тридцять відсотків | eb4656a | 6e0ed01 | e2ac378  |

Для паркування виконано сім Red/Green-кроків і два рефакторинги:
винесення констант та розділення валідації, базового тарифу й знижок.
Загалом виконано 13 Red-кроків, 13 Green-кроків та 8 рефакторингів.
Початкове падіння кожного модуля пов’язане з відсутнім імпортом, як у методичці.

Округлення паркування додано під час фінального рефакторингу:
усі комбінації заданих тарифів уже дають цілі суми, тому окремий
Red для зміни кількості десяткових знаків на цих даних не виникає.

