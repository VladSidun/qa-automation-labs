## API

- POST /auth/login: 200 з accessToken, неправильні облікові дані — 401.
- POST /orders: 201 з Location; порушення SKU — 400 INVALID_SKU.
- GET /orders та GET /orders/:id: 200; чужий/відсутній id — 404.
- DELETE /orders/:id: 204 без тіла, повторний — 404.
- Усі /orders вимагають Authorization: Bearer <token>, інакше 401.

SKU: три великі латинські літери, дефіс, чотири цифри; рівно 8 символів. Пробіли, переноси, кирилиця та інші типи відхиляються. Збереження відбувається лише після перевірки всіх позицій.

Порівняно з показовим кодом уточнено перевірку Bearer (справжній токен без префікса більше не приймається), захист від null/примітивних позицій, скінченність ціни та копіювання лише sku/price/qty у відповідь. Розрахунки знижки й доставки збережено. Базовий SKU-A замінено на ABC-1234, бо він не відповідає варіанту 12.
